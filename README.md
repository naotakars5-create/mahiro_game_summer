# 🧱 レゴあつめ ＆ まちづくり ゲーム

ブロックを あつめて、じぶんだけの いえや まちを つくる ゲームです。

## あそびかた（お子さま向け）

1. `index.html` を ブラウザで ひらいて、「スタート」を おす。
2. やじるしキー（⬆⬇⬅➡）か、がめんの したの ○ボタンで うごく。
3. フィールドに でてくる ブロックに ふれると あつまるよ。
4. うえの「つくる」ボタンを おすと、まちづくりの がめんに いける。
5. いろを えらんで、マス目を クリックすると ブロックが おけるよ。
6. 「🏠 いえを たてる」ボタンを おすと、あつめた ブロックで いえが たつよ！
7. たくさん いえを たてて、じぶんの まちを つくろう。

あつめた かずが ふえると、あたらしい いろの ブロック（みどり・むらさき）が でてくるようになります。

## 保護者の方へ

- インターネット接続やインストールは不要です。`index.html` をダブルクリックすればブラウザで遊べます。
- 進行状況（集めたブロック・作った街）はブラウザの `localStorage` に自動保存されるため、閉じても続きから遊べます。
- ファイル構成:
  - `index.html` … 画面の構造（タイトル／あつめる／つくる の3画面）
  - `style.css` … 見た目のスタイル
  - `script.js` … ゲームのロジック（移動・当たり判定・街づくり・保存処理）
- タブレットなどタッチ操作にも対応（画面下の丸ボタンで移動できます）。
- 効果音はブラウザの音声機能（Web Audio API）で簡易的に鳴らしています。右上の🔊ボタンでON/OFFできます。
